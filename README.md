Jogo de Adivinhação em Python



Um jogo simples e interativo de linha de comando (CLI) desenvolvido em Python, onde o jogador tenta adivinhar um número aleatório entre 1 e 10 sorteado pelo computador.



Funcionalidades

\* \*\*Sorteio Aleatório:\*\* Gera um novo número secreto a cada partida usando a biblioteca nativa `random`.

\* \*\*Sistema de Dicas:\*\* Informa se o palpite do jogador foi maior ou menor que o número sorteado.

\* \*\*Contador de Tentativas:\*\* Exibe quantas tentativas foram necessárias até acertar.

\* \*\*Validação de Entradas:\*\* Tratamento de erros (`try/except`) para impedir que o programa quebre caso o usuário digite letras ou números fora do intervalo permitido.

\* \*\*Replay:\*\* Permite jogar várias partidas seguidas sem precisar reiniciar o script.



Tecnologias Utilizadas

Python 3
